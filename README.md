# 🛸 Rick & Morty Explorer

A responsive web application built with **HTML, CSS and JavaScript** that allows users to browse characters from the Rick and Morty universe using the public Rick and Morty API.

## 🚀 Features

- 🔍 Search characters by name
- 🎯 Filter by status
- 👤 Filter by gender
- 🔤 Sort characters alphabetically (A-Z / Z-A)
- 📄 Pagination (20 characters per page)
- 📊 Total results counter
- 🖼️ Character details modal
- 💾 Persist filters using Local Storage
- ⚡ Debounced search input
- 💀 Skeleton Loader while fetching data
- 📱 Responsive design
